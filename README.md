# 競馬AI 🏇

JRAの過去のレースデータから、**各馬が3着以内に入る確率**を予想するAIです。
データ集め・ヒント（特徴量）づくり・学習・検証・予想アプリまで、全部自分で作りました。

毎週の重賞はこのAIで予想して、noteに予想と結果を公開しています。

---

## できること

- **レースの予想**：出走馬ごとに「3着以内に入る確率」を出して、AIの順位をつけます。
- **AIが理由を説明**：その馬の確率を上げたヒント・下げたヒントを表示します（例：「189日ぶりの休み明けで下げた」）。
- **馬の特徴をラベルにする**：`先行` `道悪◎` `冬に強い` `この舞台◎` `休み明け` など。
- **予想アプリ**：レースを選ぶと、全馬の予想と1頭ずつの説明が見られます（Streamlit）。
- **買い目の計算**：AIの確率でレースを何万回もシミュレーションして、3連複の買い目が当たる確率を出します。

> AIはオッズ（人気）を**見ずに**予想しています。人気とは別の目線で馬を評価するためです。

---

## 仕組み

```
① データを集める     netkeibaから、2015年〜のJRAの全レース結果（約57万頭分）
        ↓
② ヒントを作る       馬・騎手・調教師の「そのレースより前」の成績から、89個のヒントを計算
        ↓
③ 学習する           LightGBMで「3着以内に入るか」を学習（乱数を変えた3つのAIの平均）
        ↓
④ 予想する           当日の出馬表からヒントを作って、確率を出す（1レースの合計が3になるように調整）
```

### 使っているヒント（特徴量）89個の例

| グループ | 例 |
| --- | --- |
| レースの条件 | 競馬場、芝・ダート、距離、馬場状態、天気、頭数 |
| 馬の過去成績 | 前走の着順、過去5走の平均着順、3着以内率、上りタイム |
| スピード指数 | タイム差から計算した指数（馬場の速さで補正したものも） |
| レースの格 | 今までに走ったレースの格（1着賞金）、獲得賞金 |
| 騎手・調教師 | 前日までの3着以内率、乗った回数 |
| 同じ条件での成績 | 同じコース・競馬場・距離での3着以内率 |
| レースの中での比較 | 「過去5走の平均着順が、このレースの出走馬の中で何番目か」など |
| 調子 | 2〜3走前の着順、前走の人気と着順の差、休み明け何戦目、道悪の成績 |
| 季節・脚質など | 同じ季節の成績、先行する馬か、枠の有利さ、騎手と競馬場・調教師の相性 |

**気をつけたこと：未来のデータを使わない。**
ヒントは全部「そのレースより前」の情報だけで作っています。たとえば騎手の成績は「前日まで」です。着順やタイムなど、そのレースの結果そのものは絶対に入れていません。

## 検証の仕方

**2023年までのレースで学習 → 2024年で調整 → 2025年以降のレース（5,493レース）でテスト**

テストのレースは、学習にも調整にも一度も使っていません。「まだ知らない未来のレースを当てられるか」を確かめるためです。

### 今のAIの成績（2025年以降のテスト）

| 指標 | 全レース | 重賞（192レース） |
| --- | --- | --- |
| AUC（来る馬と来ない馬の見分けやすさ。0.5＝でたらめ、1＝完璧） | 0.80 | 0.76 |
| AI1位の馬が3着以内に来た割合 | 61.7% | 52.1% |
| （参考）1番人気の馬が3着以内に来た割合 | 64.7% | 59.4% |

**正直なところ：オッズ（みんなの予想）にはまだ勝てていません。**
AIはオッズを見ていないので、AIだけの力で1番人気に近いところまで来ている、とも言えます。過去の馬券のシミュレーションでも、どの買い方も長い目で見ると回収率は約75〜85%で、100%は超えませんでした。

## 試したこと（実験）

精度を上げるために、仮説を立てて1つずつ確かめました。どれも上と同じテストで比べています。
実験のコードと結果は [`experiments/`](experiments/) にあります。

### 1. モデルの比較 → LightGBMを使う

| モデル | AUC（全部） | AUC（重賞） | AI1位の3着以内率 | 学習時間 |
| --- | --- | --- | --- | --- |
| **LightGBM（採用）** | 0.7970 | 0.7547 | **61.5%** | 30秒 |
| CatBoost | **0.7975** | **0.7577** | 61.0% | 314秒 |
| XGBoost | 0.7953 | 0.7521 | 60.6% | 34秒 |
| ロジスティック回帰 | 0.7886 | 0.7438 | 59.8% | 12秒 |
| ランダムフォレスト | 0.7864 | 0.7329 | 59.1% | 152秒 |

LightGBM・CatBoost・XGBoostはほぼ同じ強さでした。CatBoostは10倍遅いので、LightGBMを選びました。
重賞だけ見るとロジスティック回帰が53.6%で一番でしたが、ブートストラップで確かめると差の範囲は −1%〜+11.5% で、**偶然の範囲**と判断しました（重賞は192レースしかない）。

### 2. ヒントを増やす → 効いたものだけ採用

| 試したヒント | 結果 | 採用 |
| --- | --- | --- |
| 調子（近走の流れ・休み明け・道悪の成績） | AUC +0.0019 | ✅ |
| 季節・脚質・枠の有利さ・騎手の相性・同じ舞台 | AUC +0.0013（0.7978→0.7991）、AI1位 +0.6% | ✅ |
| 騎手の人気以上率・乗り替わり・牝馬限定・血統 | ほぼ変わらず、重賞のAI1位は下がった | ❌ |
| 今日の馬場に合わせた成績（雨の日の強さ） | 少し下がった | ❌ |

最後の「雨の日の強さ」は、みんなが大事だと思っているヒントです。でもデータで確かめると、予想にはほとんど効きませんでした。道悪のレースは1頭あたり数回しか走らないので数字がぶれやすいことと、道悪でも結局は強い馬が来ることが理由だと考えています。

### 3. 学習に使う期間 → 長いほど良い

| 学習に使う期間 | AUC（全部） |
| --- | --- |
| **9年分（2015〜2023年）** | **0.7991** |
| 7年分 | 0.7987 |
| 5年分 | 0.7982 |
| 3年分 | 0.7966 |
| 2年分 | 0.7954 |
| 9年分＋新しい年ほど重く見る | 0.7990 |

「古いデータは今の競馬に合わないのでは？」と思って試しましたが、データが多いほど良い結果でした。新しい情報（最近の成績など）はヒントのほうにもう入っているからだと考えています。

### 4. 重賞ではAIの%が高く出すぎる

AI1位の確率が70%以上のとき、全レースでは約80%が3着以内に来ます。でも重賞では約55〜65%でした。重賞は強い馬がそろうので、確率を割り引いて見る必要があります。アプリでも注意を表示しています。

## フォルダの構成

```
keiba_AI/
├── src/                AI本体
│   ├── keiba.py          netkeibaからレース結果と払戻を集める
│   ├── pedigree.py       血統データを集める
│   ├── overseas.py       海外のレースの成績を集める
│   ├── features.py       ヒント（特徴量）を作る
│   ├── train.py          学習と検証
│   ├── predict_race.py   レースを予想する
│   ├── predict_day.py    1日の全レースを予想する
│   ├── results.py        レース結果と払戻を取る
│   └── combo_sim.py      3連複の買い目の当たる確率を計算する
├── app/
│   └── app.py            予想アプリ（Streamlit）
└── experiments/        実験のコードと結果
```

`data/`（集めたデータ）、`models/`（学習したモデル）、`predictions/`（予想の結果）は、GitHubには上げていません。

## 動かし方

Python 3.11 で動かしています。

```bash
# 1. 準備
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2. データを集める（src/keiba.py の最後に、取りたい年を書いて実行。数時間かかります）
.venv/bin/python src/keiba.py

# 3. 学習と検証
.venv/bin/python src/train.py

# 4. レースを予想する（日付と race_id）
.venv/bin/python src/predict_race.py 2026-11-29 <race_id>

# 5. 予想アプリを開く
.venv/bin/streamlit run app/app.py
```

コマンドは全部、`keiba_AI` フォルダで実行します。
